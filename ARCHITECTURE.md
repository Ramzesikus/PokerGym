### Точка входа для тренировок из Обучариума — построена, финальные сигнатуры
`startTraining(moduleId, customSettings)` в `js/practice/practice-router.js` — уже механизм, не заметка на будущее. `customSettings` — объект нужной для `moduleId` формы, `null`/не передан — тренировка запускается с текущими настройками (как из хаба). Реальные id — из `HUB_MODULES` в `practice.js`, не имена файлов:
- **`outs`** — `{ wantNumber, wantCategory, wantPercategory, street }`
- **`positions`** — `{ minN, maxN, format, school }`
- **`notation`** — `{ mode, rankPool, pairs, tokenType }`
- **`preflop-table`** — `{ rankPool, pairs, tokenType, rangeComplexity, showMode, probUnit, probInput }`
- **`identify-combo`** — `{ sublevel }`
- `calc-outs`, `calc-equity` — не подключены, это калькуляторы с ручным вводом, не сессии
